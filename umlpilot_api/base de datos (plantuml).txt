' ===== NOTAS =====

note left of Elemento
  **Estructura de Árbol**
  -----------------------------------
  Los elementos se organizan 
  jerárquicamente como en 
  Enterprise Architect.
  
  Un elemento puede contener 
  otros elementos (relación 
  recursiva "contiene").
  
  Esto permite:
  - Paquetes anidados
  - Clases internas
  - Estructura de proyecto
  - Explorador de proyectos
end note

note left of Paquete
  **Contenedor Jerárquico**
  -----------------------------------
  Los paquetes pueden contener:
  - Subpaquetes
  - Clases
  - Interfaces
  - Enumeraciones
  - DataTypes
  - Diagramas
  
  Representa el namespace
  en el modelo UML.
end note

note right of DataType
  **DataType UML**
  -----------------------------------
  Define un tipo de dato estructurado
  que no tiene identidad propia.
  
  Ejemplos en Java:
  - LocalDate
  - BigDecimal
  - Address (Value Object)
  
  Se representa con la palabra
  clave <<datatype>>
end note

note right of PrimitiveType
  **PrimitiveType UML**
  -----------------------------------
  Define un tipo de dato atómico
  proporcionado por el lenguaje.
  
  Ejemplos:
  - int, boolean, float, char
  - Integer, Boolean (Wrapper)
  - String (en algunos casos)
  
  Se representa con la palabra
  clave <<primitive>>
end note

note right of Note
  **Note UML**
  -----------------------------------
  Elemento de documentación
  que puede adjuntarse a
  cualquier otro elemento.
  
  Propiedades:
  - Comentarios
  - Explicaciones
  - Restricciones
  - Etiquetas de navegación
end note

note right of Literal
  **Literal UML**
  -----------------------------------
  Representa un valor constante
  dentro de una Enumeración.
  
  Ejemplo:
  enum EstadoCivil {
    SOLTERO, CASADO, DIVORCIADO
  }
end note

note right of Modelo
  **Modelo UML**
  -----------------------------------
  Representa el modelo completo
  del sistema.
  
  Contiene todos los elementos
  y diagramas del proyecto.
end note

note right of GeneracionCodigo
  **Generación SpringBoot**
  -----------------------------------
  Genera código con:
  1. Entity (@Entity)
  2. Repository (@Repository)
  3. Service (@Service)
  4. Controller (@RestController)
  5. DTOs
  6. Estructura de paquetes
  7. Dependencias (pom.xml)
  8. application.properties
end note
